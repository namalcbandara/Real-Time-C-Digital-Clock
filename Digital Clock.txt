# Real-Time Digital Clock

A sleek, terminal-based Digital Clock developed in C. This project demonstrates how to handle system time and create a continuously updating display using ANSI escape sequences.

## Features

* **Real-Time Tracking:** Fetches and displays the current system time (Hours:Minutes:Seconds).
* **Auto-Refresh:** Clears the terminal and updates the clock every second for a smooth "ticking" effect.
* **Cross-Platform Support:** Built-in compatibility for both Windows (using `windows.h`) and Unix-like systems (using `unistd.h`).
* **Visual UI:** Uses color-coded borders and text for a modern CLI feel.

## Technical Concepts

* **Time Management:** Utilizes the `<time.h>` library and `struct tm` to extract local time.
* **Terminal Control:** Uses ANSI escape codes (`\033[2J`) to clear the screen without flickering.
* **Conditional Compilation:** Uses `#ifdef` to handle different operating system sleep commands.

## How to Compile and Run

1.  Ensure you have a C compiler (GCC/Clang/MSVC).
2.  Open your terminal.
3.  Compile the code:
    ```bash
    gcc digital_clock.c -o digital_clock
    ```
4.  Run the executable:
    * On Linux/macOS: `./digital_clock`
    * On Windows: `digital_clock.exe`

## Note
To stop the clock, simply press `Ctrl + C` in your terminal.
